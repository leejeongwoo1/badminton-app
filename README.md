# 배드민턴 매칭 앱

> 체육관에 도착해서 버튼 하나로, 롤처럼 실력에 맞는 사람들과 바로 복식 게임을 치는 앱

## 해결하려는 문제

배드민턴 복식에는 4명이 필요하다. 공용 체육관에서는 인원이 많은 클럽이 코트를 먼저 차지하기 쉬워서,
클럽에 속하지 않은 개인은 칠 사람을 모으기도, 코트를 잡기도 어렵다.
클럽에 들어가면 회비가 든다.

이 앱은 **체육관에 체크인한 사람들끼리 실력(MMR)과 원하는 게임 모드에 맞춰 자동으로 매칭하고, 빈 코트까지 배정**한다.

## 핵심 기능 (MVP)

- **체크인**: 운영 시간 + GPS 반경 안에서만 체크인
- **매칭**: 게임 모드(남복 / 여복 / 혼복 / 성별 무관) 복수 선택 → 4명 매칭 → 빈 코트 배정과 동시에 게임 시작
- **불참 처리**: 게임 시작 후 3~10분 사이 불참 신고 → 게임 폐기, 나머지는 다시 매칭
- **점수 입력**: 4명 모두 입력 가능, 첫 입력 후 10분 안에 입력값이 일치하면 기록 확정
- **실력 지표**: 가입 시 급수로 초기 MMR 설정, 게임 결과로 MMR 갱신
- **체육관 등록**: 누구나 등록(자동 승인, 위치 중복 확인), 등록자가 관리자

## 기술 스택

| 서버 | Spring Boot (Java) |
| DB | PostgreSQL |
| 푸시 | Firebase Cloud Messaging |
